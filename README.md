# Shinje

Shinje, Lord of Death: weighs every deed before passing judgment.

Shinje is a risk-adaptive access control (RAdAC) system. It weighs the risk of each request before judging it, and user and entity behavior analytics (UEBA) is one of its signals: a baseline of normal activity for users and for entities such as hosts, services and API clients, against which unusual activity stands out.
